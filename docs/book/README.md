# Bolide 从入门到精通

这是 Bolide 语言的系统教程书稿，面向第一次接触 Bolide 的读者，也覆盖 AOT、FFI、并发、内存模型、标准库和工程化实践。

- [完整书稿：Bolide 从入门到精通](./bolide-from-zero-to-mastery.md)

建议阅读顺序：

1. 先读第 1-4 章，掌握安装、运行、基础语法和控制流。
2. 再读第 5-9 章，掌握函数、一等函数、闭包、集合、类、模块和错误处理。
3. 继续读第 10-13 章，理解类型系统、内存管理、并发和异步。
4. 最后读第 14-18 章，学习 FFI、AOT 发布、Web/GUI 标准库、调试诊断、测试和性能优化。

本文档以 Bolide `0.13.1` 为基准。
